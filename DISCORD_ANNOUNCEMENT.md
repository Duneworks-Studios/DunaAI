# 🚀 **Major Update: New Multi-Agent System!**

We're excited to announce a **complete overhaul** of Duna AI's agent system! We've replaced the old Chat/Coding agent setup with a powerful **8-agent tiered system** that gives you more control and better AI responses.

## ✨ **What's New:**

### **6 Premium Agents** (Pro Plan Required)
1. **🤖 Duna AI Meta Advanced** - *The Best Agent*
   - Very advanced, high quality, and fast responses
   - Highest depth and accuracy

2. **⚡ Duna AI Meta** - *2nd Best Agent*
   - Fast and simpler responses but still very advanced
   - Perfect balance of speed and quality

3. **🌌 Duna AI Universe** - *3rd Best Agent*
   - High-level agent for advanced questions and responses
   - Expert-level insights

4. **🌠 Duna AI Galaxy** - *4th Best Agent*
   - Simpler and fast responses
   - Great for quick, practical answers

5. **🪐 Duna AI Jupiter** - *5th Best Agent*
   - Simple questions and fast responses
   - Optimized for speed

6. **🌙 Duna AI Luna** - *6th Best Agent*
   - Specialized for coding and advanced technical responses
   - Expert programming assistance

### **2 Free Agents** (Available to Everyone)
1. **⭐ Duna AI Nova Advanced** - *2nd Last Agent*
   - Moderate responses but still speedy and advanced
   - Great balance for free users

2. **💫 Duna AI Nova** - *Last Agent*
   - Regular questions and responses
   - Reliable everyday assistant

## 🎯 **How It Works:**

- **Agent Dropdown**: Select any agent from the dropdown menu near the chat input
- **Plan Restrictions**: Free users can see all agents but can only use the 2 free ones (Pro agents are grayed out)
- **Smart Switching**: The system automatically ensures you're using an agent available for your plan
- **Better Responses**: Each agent is optimized for different use cases and response depths

## 🔒 **Premium Benefits:**

Upgrade to **Duna Pro** to unlock all 6 premium agents with:
- Highest quality responses
- Advanced technical assistance
- Faster processing
- Specialized agents for coding and complex questions

## 📸 **Image Analysis:**

We've also improved image analysis! You can now send images and get proper analysis from any agent.
